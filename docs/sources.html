In use

Your own source

Pulse is more than Home Assistant. The object does not care where a reading comes from: a machine's load and disks, a car's battery and tires, a boat's tanks and wind are systems with channels like any other. Home Assistant is the first source that is real; a machine, read by a small collector, is the second.

What a system is

A system is a title and a few channels. A channel reads the host's state and returns a reading, or nothing when there is nothing for it. A reading is one of three rings, a big value, one line, the things it depends on, and sometimes an alert with its actions. That is the whole contract between a host and the object.

{
  kind: 'p',                  // a band ('p'), switches ('s') or a choice ('c')
  v: 0.74,                    // the band's progress
  dial: { min: 0, max: 100, step: 1, unit: '%', label: 'charge', value: 74, id: 'battery', set: (v) => action },
  big: '74%', label: '310 km',
  ids: ['battery'],
  alert: { level: 1, big: '12%', label: 'battery', why: 'Not enough charge for tomorrow', verb: 'Schedule charging', acts: [action] },
}

Two to four channels that compete for attention, ordered front to back, make a good system. More than that is usually two systems.

What a host is

A host hands the board its systems, tells it when a thing changes, runs the actions the board hands back, and names the things. In the core it is one interface, PulseHost. The Home Assistant app makes one out of a source with three implementations (the WebSocket, the card's hass object, the demo homes); the homelab app makes one out of its collector.

Where it runs

The core is a plain module that mounts on an element and draws with CSS and a little SVG. It works inside a shadow root, which is what a Home Assistant card is, and on a round screen, which is what a boat's helm or a wall panel may be. The repository has three examples: the Home Assistant app, the homelab app over a Mac or a Linux box, and the demo app over made-up data. The steps, from the imports to the theme: In your project.
